# BrowserModelViewer

This is a model browser & viewer used browsing a model databank with various models namely in .mb, .c4d, .fbx, .obj formats.
This project is based on [React](https://react.dev/) and [PHP](https://www.php.net/)

### Prerequisites

- Node.js `>=18.17`

### Installation

Clone the repository and install dependencies:

```bash
npm install
```
### Development

To develop the app and packages, run the following command:

```bash
npm dev
```

### Build

To build the app and packages, run the following command:

```bash
npm build
```

## Project Structure

ModelViewer comprises two main components of the project. The **app** section includes the React web application and documentation. The other section is **api**, which contains the PHP api connected to the React app.
